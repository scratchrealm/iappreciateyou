# i appreciate you

The simplest way to send a little ecard to someone.

Live at [iappreciateyou.magland.org](https://iappreciateyou.magland.org).

Pick a card design, write a note, and share the link however you like. The entire
card (design, message, font, colors) is compressed and encoded directly into the
link, so nothing is ever stored on a server. Whoever opens the link sees the card
exactly as it was composed. No accounts, no ads, no tracking.

## Development

```
npm install
npm run dev
```

## Deployment

Pushes to `main` are built and deployed to GitHub Pages by the workflow in
`.github/workflows/deploy.yml`.
